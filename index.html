Split a bank OFX file that holds several accounts into one file per account

Some banks and money apps export all your accounts into a single OFX or QFX file. Actual Budget imports such a file into the one account you import from: every transaction lands there, and when the file mixes a bank account and a card, only the card is read. This page lists the accounts inside the file and gives you one file per account, so each one can be imported into its own account in Actual.

  1. Choose the file (or several) below. It is read in your browser and nothing in this page's code sends it anywhere; the page's security policy also stops its scripts from making network requests.
  2. Download the file for each account.
  3. In Actual, open each account and import its file as usual.

Each output file keeps the original header, the sign-on block and that account's statements exactly as they were in your file; only the wrapper around them is rebuilt. File names carry the account type and the last four characters of the account number. No warranty: check the transactions after importing.

Reads OFX 1 (SGML) and OFX 2 (XML) files, and QFX. Bank, credit card and investment statements are each split by account number. It has been tested with automated tests on example files and with Actual's own import code, but not in a real browser and not on a real bank export. If it does not work for you, an issue on the repo helps; please do not attach your real file, only the bank or app it comes from and the error shown.
